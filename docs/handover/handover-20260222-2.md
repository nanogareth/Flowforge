## Decisions Made

- Claude's project slug format: `C:\GitHub\Foo` → `C--GitHub-Foo` (colon→dash, separator→dash, leading dashes stripped)
- Native session detection via JSONL mtime (5-minute window) rather than process scanning — simpler, no OS-specific process inspection needed
- `getConversationHistory()` takes optional `claudeProjectsDir` param for testability without mocking `os.homedir()`
- Blue dot = native desktop Claude session; green dot = FlowForge-spawned terminal session
