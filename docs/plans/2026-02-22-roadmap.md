# FlowForge Roadmap

**Date:** 2026-02-22
**Context:** App installed on Xiaomi Poco F5, both repo creation and remote terminal used equally. Personal tool.

## Phase 1: Session Rejoining

**Status:** Design approved (see `2026-02-18-session-rejoining-design.md`)

Enable listing and rejoining running terminal sessions and resuming past Claude Code conversations from mobile. Adds project detail screen as intermediate navigation between project list and terminal.

Key deliverables:
- Server: `getActiveSessions()`, session history scanner, combined `GET /api/projects/:name`
- Mobile: project detail screen with running sessions + recent conversations
- WebView bridge: session ID persistence for reconnection

## Phase 2: Connection Reliability

**Status:** Pending — will be designed after Phase 1 testing reveals specific failure modes

Anticipated areas:
- WebSocket reconnection hardening (visual state indicators, faster detection)
- Heartbeat/ping-pong keepalive
- Tailscale failover improvements (parallel URL attempts)

## Phase 3: Terminal UX Polish

**Status:** Deferred

- Keyboard touch targets and key combos
- Scrollback/rendering performance
- Quick-action gestures
